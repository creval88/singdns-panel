# v20260518-beta2-hotfix35

本版本重点升级节点监控自动切换：从单纯延迟检测扩展为延迟、真实访问和晚高峰下载吞吐的综合判断，并修复监控页面摘要和切换记录不够清晰的问题。

## 新增
- 节点监控支持质量检测：延迟、多个真实访问 URL、质量分和持续下载速度可共同决定主备切换。
- 支持白天 / 晚高峰分时策略：可分别设置完整检测间隔和下载速度要求。
- 支持晚高峰 4K 可用性检测，通过持续下载速度和低速窗口判断节点是否“低延迟但实际很卡”。
- 自动注入仅本机监听的监控 SOCKS 入口，用于分别测试主组和备组，避免为了测试主组恢复而临时切换当前默认出口。
- 新增切换记录，单独记录何时切换、切到哪个组以及切换原因。

## 修复
- 定时任务摘要现在会显示真实策略，包括白天 / 晚高峰间隔、下载测速开关、速度阈值和异常预检状态。
- 后台 cron 每分钟触发，但未到配置间隔时只记录跳过，不会每分钟都跑完整下载测速。
- 延迟或真实访问已异常时会跳过下载测速，减少无意义流量消耗。
- 监控状态文件放到 `/opt/singdns-panel/data`，安装和升级脚本会创建并修正目录权限。
- 保存配置中心、订阅配置或手动节点配置时，会兼容监控 SOCKS 注入逻辑，避免用户更新订阅后监控入口丢失。

- 已在测试机 `10.0.0.6` 验证白天 / 晚高峰节流、下载测速、主备切换、任务摘要和切换记录。
- `go test ./...` 已通过。
